**المعمارية الجوهرية — المسار المزدوج:** كل بيانات قد تكون شخصية أو عائلية حسب `householdId`:
```
users/{uid}/...        ← شخصي
households/{hhId}/...   ← مشترك (عائلة)
```
كل دالة بـ`services/firestore.ts` تقبل `householdId?` لتقرّر المسار. `getUserSettings` يدمج المشترك (ميزانية/فئات/دخل) مع الشخصي (نبرة/إشعارات/عملة). كل مستند يحفظ `uid` منشئه.

## التدفق الرئيسي (مستخدم جديد)
1. الهبوط → CTA يقود لـ `/signup` (لا `/login`).
2. معالج إعداد (5 شاشات: ترحيب → دخل [اختياري، زر تخطّي] → ميزانية → أسرة → انطلاق) — "تخطّي الباقي" من الميزانية فصاعداً يحفظ (دخل + ميزانية تلقائية 70% + أسرة)، لا يتجاهل.
3. شاشة الانطلاق → زر "سجّل أول مصروف" يقود مباشرة لـ`/add-expense`.
4. الجولة التعريفية تُؤجَّل حتى بعد أول مصروف فعلي (لا فور انتهاء المعالج).
