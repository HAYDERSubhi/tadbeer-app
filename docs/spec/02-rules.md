## قوانين المنتج
- الوضع الفاتح هو الافتراضي دائماً — قرار مقفول صراحةً، لا يُغيَّر بلا طلب صريح.
- موبايل حصراً بالتصميم — أي تعديل/تحسين للهاتف فقط، مستخدم الحاسبة لا يُحسب بقرار التصميم.
- التطبيق يعمل بحساب زائر مؤقت (Anonymous) كخيار ثانوي، وبحساب دائم (بريد/جوجل) كمسار أساسي — ليس "بلا حساب كاملاً".

## 🔒 قوانين الاتجاه (RTL)
| القانون | كيف يُفحص |
|---|---|
| الجذر يحمل الاتجاه | `dir="rtl"` في `layout.tsx:102` |
| ممنوع `ml- mr- pl- pr- left- right- text-left text-right` | البديل `ms- me- ps- pe- start- end- text-start text-end` — البحث عن الممنوع يجب أن يرجّع صفراً |
| شريط أي تقدّم يمتلئ من اليمين | عنصر التعبئة `start-0` لا `left-0` (معالج الإعداد يستخدم عرضاً نسبياً، لا `translateX`) |
| كل رقم مع وحدة داخل `<bdi>` | يمنع انقلاب «50 د.ع» إلى «د.ع 50» |
| الأيقونات الاتجاهية تنعكس كالمرآة | كل سهم رجوع/تالي/سابق عليه `rtl:-scale-x-100` أو مكافئها |
| **أسلوب واحد للاتجاه، لا اثنان** | وراثة من الجذر فقط — لا قلب يدوي إضافي بأي مكوّن |

## قوانين إضافية خاصة بهذا المشروع (دروس حقيقية — لا نظرية)

### Firebase / مصادقة
- **`firebase-admin` مثبَّت عمداً على `^12.7.0` — ممنوع رفعه لـ 14** بلا حل بديل. النسخة 14 تجلب `jose@6` (ESM فقط) فتكسر كل مسار admin على Vercel (`ERR_REQUIRE_ESM`) بصمت — لا يظهر محلياً بـ`next dev`. اكتُشف 2026-06-24.
- **مزوّد Email/Password يجب أن يبقى مفعّلاً** بـ Firebase Console (Authentication → Sign-in method). تعطيله = `auth/operation-not-allowed` قاتل عند كل تسجيل بريد جديد. المزوّدون المطلوبون: Email/Password + Google + Anonymous.
- **`authDomain` = `www.tadbeer.app`** (لا `iraqi-budgeteer.firebaseapp.com`) + rewrites بـ`next.config.js` لـ `/__/auth/*` و`/__/firebase/*`. أي نطاق جديد يُضاف بثلاثة أماكن معاً: Firebase Authorized domains + OAuth origins + redirect URIs.
- **الدخول بجوجل عبر `signInWithRedirect`/`linkWithRedirect` (تحويل كامل الصفحة) — ممنوع popup.** popup كان يفشل أول نقرة على الجوال (الجمهور حصراً جوال). مؤكَّد على الإنتاج بجهاز حقيقي.
- مفتاح Gemini AI: `GEMINI_API_KEY` (لا `GOOGLE_API_KEY`) — الخلط بينهما يعطّل كل ميزات الذكاء الاصطناعي بصمت.

### أندرويد (TWA)
- **بصمة `assetlinks.json` يجب أن تطابق مفتاح توقيع Google Play** (Play App Signing certificate)، **لا مفتاح الرفع (upload key)** — خلطهما يُظهر شريط عنوان المتصفح بدل ملء الشاشة. الملف يُخدَم حيّاً من الدومين، تصحيحه لا يحتاج رفع تطبيق جديد.
- **Target SDK 35 يفرض edge-to-edge:** لازم `viewportFit: 'cover'` بـ`layout.tsx` + معالجة `env(safe-area-inset-*)` بالهيدر والشريط السفلي، وإلا يظهر شريط ألوان "ميت" عند حواف الشاشة.

### iOS / PWA
- **أيقونة الشاشة الرئيسية (`apple-touch-icon`) يجب أن تكون معتمة (خلفية فيروزية صلبة)** — iOS يتجاهل الشفافية فتظهر الأيقونة بيضاء/فارغة. **بالمقابل** شارة إشعار أندرويد يجب أن تبقى **شفافة منفصلة** — عكس الاثنين يكسر أحدهما.
- **إعادة تحميل Service Worker التلقائية تستخدم `reloadWhenIdle()`** (من `lib/reload-when-idle.ts`) **لا `window.location.reload()` مباشر** — `skipWaiting:true` يُفعّل تحديثاً صامتاً قد يضرب أي مستخدم بمنتصف نموذج مفتوح.

### الكود / البنية
- **ملفات `'use server'` تصدّر دوال `async` فقط** — تصدير `const`/`interface` لكائن حقيقي (مثل Zod schema) يُسقط **كل** Server Actions بالتطبيق دفعة واحدة (حادثة إنتاج كاملة 2026-07-08/09 أثناء حملة إعلانية نشطة).
- Server Actions ترجع `{ok:true,data} | {ok:false,error}` دائماً — **ممنوع الرمي (`throw`)**: Next.js يحذف رسالة الخطأ الحقيقية بالإنتاج ويستبدلها برسالة مبهمة.
- ملفات SEO حساسة **لا تُحذف ولا تُغيَّر:** `public/google2b76e81148fe227e.html` (تحقق GSC)، `public/robots.txt` (مفتوح للفهرسة عمداً)، `src/app/sitemap.ts` (النطاق `www.tadbeer.app`).
- الآلية: `push إلى master` → **نشر تلقائي فوري** على Vercel — **أكّد قبل كل push** حتى لو وافق صاحب المشروع بجلسة سابقة (فعل خارجي صعب التراجع).
