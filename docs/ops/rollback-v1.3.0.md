# خطة التراجع — v1.3.0 (سفراتي)

**اقرأ هذا قبل النشر لا بعده.** الهدف: إرجاع الوضع كما كان بأقل زمن ممكن.

---

## الحقيقة المطمئنة أولاً

**لا يوجد ما «يُفَك».** الإصدار لم ينشئ سكربت هجرة، ولم يكتب على أي مستند قائم، ولم يغيّر صلاحيات ولا فهارس. التراجع = **إرجاع الكود فقط**، وبيانات المستخدمين لا تتأثر بأي حال.

---

## الخطوة ١ — أرجع الموقع لآخر نسخة سليمة (دقيقتان)

من لوحة **Vercel** → المشروع → تبويب **Deployments** → اختر آخر نشرة قبل v1.3.0 → **⋯ → Promote to Production**.

- **لا يحتاج git ولا بناء جديد** — النشرة القديمة مبنية وجاهزة، والترقية فورية.
- خلال دقيقة يعود كل مستخدم للنسخة السابقة تلقائياً، **بلا أي إجراء منه** (التطبيق غلاف حول الموقع).

> ⚠️ لو كان التطبيق مفتوحاً عند مستخدم لحظتها، قد يبقى على النسخة الجديدة حتى يُغلقه ويفتحه. الأمر يستوي خلال دقائق.

## الخطوة ٢ — أرجع الفرع الرئيسي (خمس دقائق)

بعد استقرار الموقع، أرجع `master` لحالته السابقة حتى لا تعيد أي نشرة لاحقة الكودَ المعطوب:

```bash
git checkout master && git revert --no-edit 594a468..HEAD && git push
```

- **`revert` لا `reset`** — يُنشئ نقضاً جديداً ويحفظ التاريخ، فلا يُكسر أي نسخة عند أحد.
- بديل أبسط لو ترددت: اترك `master` كما هو واكتفِ بالخطوة ١ حتى نراجع سوياً.

## الخطوة ٣ — نظّف ما أنشأه المستخدمون (فقط إن لزم)

**غالباً لا تحتاجها.** البيانات القديمة سليمة، والسفرات التي أُنشئت خلال فترة النشر تبقى محفوظة بلا ضرر — وتظهر مصاريفها بشاشة المصاريف كالمعتاد.

**الأثر الوحيد المرئي بعد التراجع:** أي مصروف وُسم بسفرة تظهر فئته **«محذوفة (سفر)»** بأيقونة سلّة، لأن النسخة القديمة لا تعرف الفئة الجديدة. **المبلغ والتاريخ والعنوان كلها سليمة** — التسمية فقط.

لو أزعجك ذلك، أمامك خياران:
1. **الأفضل: لا تفعل شيئاً.** أعِد النشر بعد الإصلاح فتعود التسمية صحيحة تلقائياً.
2. لو أصررت على التنظيف الفوري: اطلبه مني — يُعدَّل حقل الفئة لتلك المصاريف فقط، بلا مساس بمبالغها.

---

## علامات تستدعي التراجع فوراً

- شاشة المصاريف أو الإحصائيات لا تفتح أو تعرض أرقاماً مختلفة عن أمس.
- شريط ميزانية الشهر بالشاشة الرئيسية تغيّر رقمه بلا سبب.
- فئة «سفر» تظهر بقوائم اختيار الفئة (يجب ألّا تظهر إطلاقاً).
- مربع «ضمن سفرة» يظهر لمستخدم لا يملك أي سفرة.
- تعذّر حفظ مصروف عادي من الشاشة الرئيسية.

## علامات **لا** تستدعي التراجع

- ملاحظة على شكل أو نص داخل شاشات «سفراتي» نفسها — تُصلَح بنشرة تالية.
- ظهور أيقونة «سفراتي» بشريط الأدوات — مقصود.
- مربع «ضمن سفرة» يظهر لمستخدم **عنده سفرة غير مُغلقة** — مقصود.
