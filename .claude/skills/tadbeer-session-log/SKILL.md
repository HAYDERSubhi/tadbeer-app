# تسجيل عمل الجلسة في «الوضع الحالي»

الهدف: ألّا تدفع الجلسة القادمة ثمن ما تعلّمته هذه الجلسة مرّتين. قسم «الوضع الحالي»
في `CLAUDE.md` هو الذاكرة الوحيدة التي تُقرأ تلقائياً بكل جلسة جديدة — ما لا يُكتب فيه
يضيع، وما يُكتب فيه خطأً يُضلّل جلسات كاملة.

## الخطوات — بالترتيب، ولا تُقفز واحدة

### 1. اقرأ قبل أن تكتب
اقرأ قسم «الوضع الحالي» **كاملاً** أولاً، وقارنه بسجلّ الالتزامات الفعلي:

```bash
git log --oneline -25 && git status --porcelain
```

- **لا تُعِد كتابة ما هو مسجَّل** — أضف الناقص فقط.
- إن ظهر التزام لا تعرفه ⇒ نسختك من `CLAUDE.md` قديمة، أعد قراءتها من القرص قبل التعديل
  (انظر قاعدة «جلسة واحدة تكتب» في `CLAUDE.md`).
- إن لم يكن في الجلسة عمل جديد يُسجَّل، **قل ذلك صراحةً ولا تخترع بنوداً** لتملأ القسم.

### 2. صنّف كل بند في خانته الصحيحة
| الخانة | ما يدخلها | لماذا الخانة مهمّة |
|---|---|---|
| ✅ أُصلح ونُشر ومُتحقَّق منه | عمل وصل الإنتاج وتأكّد | كي **لا يُعاد** عمله |
| 📌 قرار صاحب المشروع | خيار حسمه هو | كي **لا يُناقَش** من جديد |
| ⏸️ مُؤجَّل بقراره | عمل معروف ومتروك عمداً | كي **لا يُبدأ بلا إذنه** |
| ⛔ فخّ اكتُشف | ما يبدو إصلاحاً سهلاً وهو يكسر | كي **لا يقع فيه غيرك** |

الخانة الخاطئة أسوأ من عدم التسجيل: بند مؤجَّل كُتب كـ«مُصلَح» يجعل جلسة قادمة تبني فوق أرض فارغة.

### 3. مع كل بند، ثلاثة إلزامية
1. **لماذا** — العطل الجذري لا وصف العَرَض («التنقّل بـ`next/link` يجلب حمولة RSC لا مستنداً» لا «الأوفلاين ما يشتغل»).
2. **رقم الالتزام** — `abc1234` كي يُقرأ الـ`diff` عند الشكّ.
3. **تحذير صريح** بصيغة `⛔ لا تُعِد …` / `⛔ لا تحذف …` — واذكر **ما الذي سيُكسَر** إن أُعيد.

### 4. حدّث سطر الرأس
```
> آخر تحديث: **YYYY-MM-DD** · النسخة المنشورة وقتها: `<آخر التزام كود فعلاً منشور>`
```
⚠️ «النسخة المنشورة» = آخر التزام **كود** نزل على الإنتاج، لا آخر التزام توثيق.
والدفع ≠ النشر — تحقّق أن النسخة نزلت فعلاً قبل أن تكتبها.

### 5. ⛔ لا تسجّل ما لم تتحقّق منه
- كل بند في «✅ أُصلح ونُشر» يحتاج دليلاً فعلياً (استجابة إنتاج، وجود النصّ في الحزمة المنشورة، معاينة على جهاز حقيقي).
- ما لم تستطع اختباره **يُذكَر صراحةً مع سببه** — لا يُحذف ولا يُترك موهماً بأنه مُتحقَّق منه.
  أمثلة حقيقية من هذا المشروع: عامل الخدمة لا يُسجَّل في متصفّح جلسة Claude · الشاشات خلف
  تسجيل الدخول لا تُعايَن من الجلسة · متغيّرات `firebase-admin` غائبة محلياً.
- **قِس قبل أن تدّعي**: لا تصف حلاً بـ«يعالج كذا» بلا رقم يُسنده.

### 6. ادفع التوثيق
```bash
git add CLAUDE.md && git commit && git push
```
رسالة الالتزام بصيغة `docs(claude): …` بالعربية، تصف **ما أُضيف للذاكرة** لا ما أُصلح بالكود.

## قواعد الكتابة
- **عربية بسيطة** لا عامية (استثناء «كرومي» وحده — انظر `CLAUDE.md`).
- لا تُطِل: البند الذي لا يُقرأ لا يحمي أحداً. سطران أو ثلاثة، وأثقلها التحذير.
- لا تلمس أي كود أو إعداد أثناء هذه المهمة — **توثيق فقط**، ما لم يُطلب غير ذلك صراحةً.
